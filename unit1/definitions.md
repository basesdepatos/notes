## Definition and Examples

### File Types and Formats

A **file type** refers to the format or structure of a file that defines its contents and how it can be processed. Here are 10 examples of common file types and formats:

1. **Text file (.txt)** - A plain text file, generally containing unformatted text.

2. **JPEG image (.jpg)** - A file format commonly used for compressed photos.

3. **PNG image (.png)** - A file format for images with lossless compression.

4. **Portable Document Format (.pdf)** - A format used for documents and forms.

5. **MP3 audio file (.mp3)** - An audio file format that uses lossy compression for music or sound recordings.
   
6. **MP4 video file (.mp4)** - A file format for multimedia content with both video and audio.

7. **Hypertext Markup Language (.html)** - A language used to structure content on the web.

8. **Microsoft Word document (.docx)** - The file format for a Microsoft Word document.

9. **Microsoft Excel spreadsheet (.xlsx)** - The file format for a Microsoft Excel spreadsheet.

10. **ZIP compressed file (.zip)** - A compressed file format that contains one or more files.

### Unicode

**Unicode** is a character encoding standard that enables computers to represent and manipulate text from multiple writing systems. It provides a unique code point for each character, allowing for the consistent representation of text across different platforms and languages. For example, the character "A" has the Unicode code point U+0041, and the character "¡" has U+00A1.  

### XML

**XML** (Extensible Markup Language) is a flexible text format for storing and transporting data. It uses tags to structure data in a hierarchical format. XML is often used in web services and data interchange between systems. An example of XML:

```xml
<book>
  <title>Introduction to Programming</title>
  <author>John Doe</author>
  <year>2024</year>
</book>

### ASCII

**ASCII** (American Standard Code for Information Interchange) is a character encoding standard that represents text in computers. It includes 128 characters, including control characters and printable symbols. For example, the letter "A" is represented by the ASCII code 65.  

### Binary File

**Binary File** is a file that contains data in a format that is not human-readable, meaning the data is stored in binary (0s and 1s). Unlike text files, binary files are used to store more complex data, such as images, audio, video, or executable programs. For example, `.exe` files, `.jpg` images, and `.mp3` audio files are all binary files.
